# 实验报告与 Overleaf 编译

本目录保存最终实验报告及其全部插图。上传 Overleaf 时，将本目录中的
`main.tex` 和四张 `fig*.png` 图片放在同一项目根目录，并在
**Menu -> Compiler** 中选择 **XeLaTeX**。

文件说明：

- `main.tex`：最终 LaTeX 源文件；
- `实验报告_最终版.pdf`：已编译的 14 页报告；
- `fig1_rechorus_pipeline.png`：ReChorus 统一实验流程；
- `fig2_experiment_process.png`：实验执行与中断审计流程；
- `fig3_early_stop_curve.png`：SimGCL 早停曲线；
- `fig4_full_results.png`：完整数据结果对比；
- `generate_report_figures.py`：四张插图的可复现生成脚本。

提交报告前，请填写封面中的姓名、学号和小组信息，并补充正文中的代码仓库
地址与实际小组分工。
